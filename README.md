# \# Engineering Workspace

# 

# > A long-term engineering workspace for industrial software development, AI collaboration, and reusable engineering knowledge.

# 

# \---

# 

# \# Vision

# 

# Engineering Workspace is \*\*not\*\* a source code repository.

# 

# It is the engineering operating system behind every software project.

# 

# This repository defines:

# 

# \- Engineering standards

# \- AI collaboration rules

# \- Project organization

# \- Reusable templates

# \- Long-term engineering memory

# \- Development workflow

# 

# Every project should follow the same engineering methodology.

# 

# \---

# 

# \# Core Principles

# 

# 1\. Documentation is the source of truth.

# 2\. Standards are global, implementation is project-specific.

# 3\. Every project should be reproducible.

# 4\. AI assists development but never replaces engineering judgment.

# 5\. Reusable knowledge must be accumulated continuously.

#

# \## docs/

# 

# Contains engineering documentation.

# 

# Including:

# 

# \- Development Standards

# \- Coding Style

# \- Git Workflow

# \- Naming Convention

# \- Communication Rules

# \- SOP

# \- Architecture Guide

# 

# These documents define \*\*how engineering should be performed\*\*.

# 

# \---

# 

# \## memory/

# 

# Long-term engineering memory.

# 

# Contains reusable experience instead of project history.

# 

# Examples:

# 

# \- common mistakes

# \- reusable solutions

# \- engineering patterns

# \- design decisions

# \- optimization experience

# 

# Anything that can help future projects belongs here.

# 

# \---

# 

# \## projects/

# 

# Every software project lives here.

# 

# Example:

# 

# ```

# projects/

# 

# MES/

# 

# WMS/

# 

# ERP/

# ```

# 

# Each project should be independent.

# 

# No project should affect another project.

# 

# \---

# 

# \## templates/

# 

# Reusable templates.

# 

# Including:

# 

# \- Project Template

# \- Requirement Template

# \- Architecture Template

# \- Review Template

# \- Release Template

# 

# Every new project starts from templates.

# 

# \---

# 

# \## archive/

# 

# Archived projects.

# 

# Projects that are no longer maintained should be moved here instead of deleted.

# \# Creating a New Project

# 

# Create a new folder under:

# 

# ```

# projects/

# ```

# 

# Example:

# 

# ```

# projects/

# 

# MES/

# ```

# 

# Then copy the project template into the new folder.

# 

# Do not create project structures manually.

# 

# \---

# 

# \# Engineering Memory

# 

# Engineering memory is one of the most important assets.

# 

# Every completed task should consider:

# 

# \- Did we solve a reusable problem?

# 

# \- Did we discover a better workflow?

# 

# \- Did we avoid a common mistake?

# 

# If yes,

# 

# Update:

# 

# ```

# memory/

# ```

# 

# instead of writing the same experience repeatedly.

# 

# \---

# 

# \# AI Collaboration

# 

# AI is an engineering assistant.

# 

# AI should:

# 

# \- follow standards

# \- explain important decisions

# \- avoid assumptions

# \- ask when requirements are unclear

# \- update documentation together with code

# 

# AI should never:

# 

# \- invent requirements

# \- ignore project documentation

# \- bypass engineering standards

# \- silently modify unrelated files
